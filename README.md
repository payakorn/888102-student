## Notebooks

Sign in to Google, open a notebook from the table above, then
**File -> Save a copy in Drive** so your work is kept. Run the cells in order:
a later cell uses variables made by earlier ones. The first code cell imports
numpy, pandas and matplotlib, and every notebook already carries the outputs,
so you can read it before running anything.

You can also browse them at
https://colab.research.google.com/github/payakorn/888102-student and pick a notebook from the
file browser.

## Hands-on decks

https://payakorn.github.io/888102-student/hands-on/

The code boxes are live: press **Run Code** (or Ctrl/Cmd + Enter) and the
result appears below the box. Two things to know -- the page needs internet,
because the Python engine is downloaded when it opens, and it **forgets
everything when reloaded**, including your edits. For work you want to keep,
use the notebook in Colab.
