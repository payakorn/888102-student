# 888102 Big Data Analytics -- Student Materials

International College of Digital Innovation, Chiang Mai University.

This repo holds the chapter notebooks and the interactive in-browser practice
decks for course 888102. It does not include lecture slides, the exam bank,
or any instructor material -- ask your instructor for those separately.

## Notebooks

Each `chNN_*.ipynb` is a chapter notebook: theory, worked examples, and a
graded homework section. Open one directly in Colab:

- Click a notebook's Colab badge below, or
- Go to https://colab.research.google.com/github/payakorn/888102-student, sign in, and pick
  the notebook from the file browser.
